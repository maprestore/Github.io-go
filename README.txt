QUICK START — FRONTEND ONLY (No backend)
---------------------------------------------------------------
1. Unzip the package
2. Open index.html in your browser
   All pages, layout, and styling work immediately.

Note: Live tracking features (shipment lookup, stats bar)
require the backend server and database. See docs/ for setup.

---------------------------------------------------------------
FULL STACK SETUP
---------------------------------------------------------------
Requirements:
  - Node.js 18+
  - A free Supabase account (database)
  - A free Render account (backend hosting)

Setup in 3 steps:
  1. Create a Supabase project and run the SQL schema in docs/
  2. Deploy server/ to Render, set 3 environment variables
  3. Update API_BASE in the HTML files with your Render URL

Full instructions: docs/DEPLOYMENT-GUIDE.md

---------------------------------------------------------------
CUSTOMISATION
---------------------------------------------------------------
All pages use:
  - Tailwind CSS (CDN — no build step needed)
  - Font Awesome 6 (CDN)
  - Plus Jakarta Sans (Google Fonts, CDN)

To rebrand:
  - Replace "LogiSwift" with your company name (Ctrl+F → Replace All)
  - Change the blue colour scheme by editing Tailwind classes
    (blue-600 → your-color-600 etc.)
  - Update contact email in the footer and contact section
  - Replace placeholder team members in about.html
  - Update the CNAME file with your domain
